# 到手价与凑单

比价单位是用户需要的同一套东西。先统一规格、数量、随附配件、配送地区和币种，再找每种方案真正需要付的钱。

| 遇到的情况 | 如何计算或展示 |
| --- | --- |
| 已选规格的结算金额 | 以该账号页面列出的实付为准。核查含运费与否、已减哪些优惠、是否用了个人积分或余额。用余额支付的部分也是支出。 |
| 公开价、会员券或活动预告 | 核对生效时间、商品范围、叠加顺序、门槛按哪个金额计算。未确认的优惠单列为条件价。 |
| 低价款缺配件 | 把满足同一需求的配件和额外运费加回去。用户家里已有可用配件时，按实际新增支出算。 |
| 跨店凑单 | 分开计算只买目标商品、买原本就要的整篮商品、为领券额外买东西三种相关情形。与不参加活动时购买同样必需品的可行方案比较。 |
| 爆料、拼团或返利 | 查活动时效、成团条件、返利方式。延后到账或仅限下次抵扣的金额单列。无法核实实付的链接可作为询价线索。 |

**算例**（虚构）。书架当前结算价 168 元，已扣会员折扣并包邮。明天有满 200 减 20 的活动，假设书架价格不变，按会员折后价计门槛，两件都参加且仍包邮。另一本书 36 元。

- 本来就要买书，今天同篮 204 元，明天同篮 184 元，整单可省 20 元。如果书单买也是 36 元，且把它作为固定支出，新增书架相当于付 148 元。商家对单品的优惠分摊以订单明细为准。
- 原本只买书架，明天临时加书要付 184 元，比今天单买多花 16 元。若不想要这本书，今天单买更合算。

条件不齐时，写出算式里缺哪一项，以及它是否会改变建议。例如尚未确认书架参加活动，168 元可以作为已知价，184 元只作为满足活动条件时的整单价。
